## 2. 检查顺序与设计思路

先确认基线和可用环境，再测最小功能，随后测试生命周期竞态，最后是编辑器与真实构建。静态阅读、编译、Play Mode、Player、性能结论分别记录，不能相互代替。

Unity 操作使用项目允许的 CLI；不可达时记录限制并给出手工步骤，不改 YAML，不以批处理绕过当前 Editor 访问边界。只有“要求静态检查”时不升级成运行测试。

## 3. 16-A：类型与代码边界

- [ ] 数据类型优先 readonly struct，序列化可变配置使用普通 struct。
- [ ] 结构体参数/返回均按值；不存在结构体 in/out/ref 参数和 ref 返回。
- [ ] 只读快照通过构造函数赋值，没有 internal set 等可变入口。
- [ ] 数据未经 object/接口装箱；可变 struct 集合元素修改有正确写回。
- [ ] class 均有继承/行为/稳定身份/生命周期理由，未把任务状态复制进结构体。
- [ ] Runtime 不引用 GameLogic/UnityEditor；Editor 程序集依赖精确。
- [ ] 池级计时的两个阻碍项 `ActiveCount` / `_pendingPrewarmCount` 只在状态转换处增减，`TryBeginIdle()` 是唯一写 `IdleStartSeconds` 的入口。
- [ ] 不存在每帧无条件写空闲起点的代码路径（搜索 `IdleStartSeconds` 的全部赋值点逐一确认）。
- [ ] 公共接口与当前调用方一致，旧对象池无双重所有权。

## 4. 16-B：运行验收矩阵

| 场景与操作 | 预期结果 | 状态 |
|---|---|---|
| 空合法配置初始化；不挂 Monitor | 模块运行，零池，无可视化依赖 | [ ] |
| 缺 Setting、空池名、非法时间/数量 | 明确失败，无半初始化（**重名不在构建阶段拦**，由编辑器诊断标红；发布版若真重复，后者覆盖前者） | [ ] |
| 地址无效、预制体不在采集目录、远端包未下载 | 建池明确失败，无半建池，无空对象占位 | [ ] |
| 两个池引用同一地址 | 各自持有独立引用计数；释放一个池不影响另一个 |
| 未预热直接 Spawn | 返回"池未建"明确失败，不卡帧、不隐式发起加载 | [ ] |
| 建池：首次调 TryGetPoolOrCreate、重复调用、底层已有同名池 | 同步加载一次预制体；重复调用命中 `_pools` 不再加载；底层重名**不在本层拦**，由 `CreateSingleSpawnObjectPool` 抛 `Already exist` 异常 | [ ] |
| 建池预热（`PrewarmCount > 0`） | 建池那一帧不建实例；预热期间不计时；`Update` 按该池 `PrewarmPerFrame` 推进到目标；无法增长当帧结束；结算那一刻才开始计时 | [x] |
| 建池期间 Shutdown | 不适用：建池同步，中途没有可插入 `Shutdown` 的窗口 | — |
| 建池被取消 | 不适用：同步加载没有取消语义，也就没有 `await` 回调需要幂等 | — |
| ClearUnused 后释放池 | 空闲实例销毁，预制体引用只在池销毁时归还一次 | [ ] |
| 池释放含仍在借出的实例（force） | 先销毁实例再归还引用，无残留材质丢失或重复归还 | [ ] |
| 预热超过 Capacity/Max | 配置拒绝或请求 Rejected，不无限循环 | [ ] |
| 第一次/再次 Spawn，OnEnable 读取变换 | 父节点、位置、旋转、缩放已准备好 | [ ] |
| 世界/局部坐标，非单位缩放父节点 | 遵循文档空间与 localScale 合同 | [ ] |
| Spawn<T> 缺根组件 | 无遗留占用，不激活 | [ ] |
| 回调抛异常、准备时自我回收 | 清理到位，失败透明，不破坏新租约 | [ ] |
| OnEnable/OnDisable 内重入 | 旧操作不返回/回收新租约 | [ ] |
| 隐藏借出对象、重复归还、归还外部对象 | 借出状态不由激活推断；重复/外部对象拒绝（`bool Despawn(GameObject)` 已按"索引命中 + 属于本池 + 仍为借出态"三条件拒绝，第 04 步落地） | [x] |
| A 延时 → 提前归还 → B 复用 | A 任务不能回收 B | [ ] |
| 同租约替换计划、外部取消、关闭池 | 最新计划生效，取消无成功通知 | [ ] |
| 包装复用后的旧 finally/销毁通知 | 不能清除新实例的状态和任务 | [ ] |
| 预热 N、重复/同池并发/跨池预热 | 数量真实、预算按池各自算（不共享全局额度）、请求可独立取消 | [ ] |
| 预热中销毁池并同名重建 | 旧请求不转移到新池 | [ ] |
| Max 达上限但有空闲 | 允许复用；没有空闲才失败 | [ ] |
| Capacity=0、超容量 Unspawn | 同步释放后索引/计数正确，不访问回收包装 | [ ] |
| ClearUnused/ReleasePool/UnregisterPool | 对占用、配置与资源引用的处理符合不同合同 | [ ] |
| 外部 Destroy、场景 parent 销毁 | 最终清账，不访问失效 Transform | [ ] |
| 从未激活预热对象被销毁 | 兜底清理有效，不再借出失效对象 | [ ] |
| 整池过期：空池（0 实例）达到 PoolExpireTime | 从建池时刻起算，到期释放运行池与容器，配置与 SO 定义保留 | [ ] |
| 整池过期：池内全为 Idle | 到期连同全部空闲实例一起销毁，不残留容器 | [ ] |
| 整池过期：仍有借出对象 | 不过期；快照显示 `ActiveLease`，倒计时不推进 | [ ] |
| 整池过期：最后一个对象归还 | 从归还那一刻起算**完整**时长，不因之前已超时立刻释放 | [ ] |
| 整池过期：倒计时中途有新借出 | 本轮计时作废；再次归零后重新算完整时长 | [ ] |
| 整池过期：借出对象被业务 Destroy | 清账后 `ActiveCount` 归零并开始计时，池最终能释放（不出现"永远有 1 个占用"） | [ ] |
| 整池过期：预热期间 | 不计时；预热进行中不释放池 | [ ] |
| 整池过期：预热完毕 | 从最后一个预热请求终结那一刻开始计时 | [ ] |
| 整池过期：预热 NoProgress / 取消 / Rejected | 都算终结，预热计数归零后开始计时，不永久停在"预热中" | [ ] |
| 整池过期：预热因 Total >= target 提前返回 | 续期一次，不在紧接着的检查点被销毁 | [ ] |
| 整池过期：查询快照 / 打开 Monitor / 手动刷新 | 不续期、不改 `IdleStartSeconds`，池按原计划释放 | [ ] |
| 整池过期：底层按实例过期清理 Idle | 不重置池级计时 | [ ] |
| 整池过期：PoolExpireTime = 0 | 永不整池过期，校验不报错 | [ ] |
| 配置被手改成非法值（空池名 / 负容量 / 预热超 Capacity） | 初始化明确失败并给出条目序号、池名与原因，不抛未处理异常、不半初始化 | [ ] |
| 发布版构建产物 | 不含 `TEngine.Editor` 的诊断代码，也不含 `GameObjectPoolValidator`（整段 `#if UNITY_EDITOR`）：产物里搜不到该类型与任何失败文案 | [ ] |
| 整池过期：释放后同名 Spawn | 通过 TryGetPoolOrCreate 懒建新池、新世代；旧延时任务与旧销毁通知不能命中新池 | [ ] |
| 整池过期：释放失败（存在未清账项） | 保留池并等下一个检查点，不升级为强制销毁 | [ ] |
| 重复 Shutdown、退出后再初始化 | 幂等，无旧任务跨生命周期生效 | [ ] |
| 退出顺序 | 池先关、单例后释放；业务单例不得在 `Release` 中归还池对象，玩法退出须自行归还 | [ ] |

~~~text
最关键租约用例:
  a = Spawn(pool)
  安排 a 延时回收
  立即归还 a
  b = Spawn(pool)（确认实际复用了同一 GameObject）
  等待旧延时到期
  断言 b 仍处于本次借出状态
  再主动归还 b 并检查计数
~~~

不要只看物体“消失了”；同步检查 IsManaged/IsSpawned、总数和当前租约。
