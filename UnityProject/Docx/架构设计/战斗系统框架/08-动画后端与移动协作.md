# 动画后端与移动协作

日期：2026-10-25；v0.1。对应原文 01/02/03/08/09。

## 1. 统一驱动，不抹平后端

ActionTimeline 提供动作时间、通道、权重、绑定和事件；表现 Adapter 负责实际渲染。后端可以使用自己的资源与求值器，逻辑命中不依赖后端 AnimationEvent。

| 后端 | 实现方式 | 限制 |
|---|---|---|
| SpriteSequence | 预载Sprite索引，按逻辑帧换图 | 无真实骨骼混合；可选叠影只是表现 |
| AnimationClip | 手动控制 PlayableGraph，采样片段时间及混合 | Avatar、Mask、RootMotion需要单独配置与验证 |
| Spine | 使用匹配版本的官方Runtime，外部时间驱动动画状态 | 附件、皮肤、约束、混合需要原生语义；许可证另核 |

原文“Spine挥砍接Sprite特效”应建成 Body=Spine + Effect=Sprite 两个表现绑定；不应要求同一身体渲染器在不兼容资源间自动变换。依据：[Spine Skeleton 源码](https://github.com/EsotericSoftware/spine-runtimes/blob/4.3/spine-csharp/src/Skeleton.cs)、[Unity Animation Jobs 示例](https://github.com/Unity-Technologies/animation-jobs-samples)。

## 2. SpriteSequence 具体算法

N张图、T总帧，当前f属于 `[0,T)`：`index=min(N-1,floor(f*N/T))`。例如4图10帧：图0占0–2，图1占3–4，图2占5–7，图3占8–9。若T<N，默认导出失败，避免一些图片永远无法展示；需要跳图时用明确的抽帧导出选项。

进阶可配置每图 durationFrames，所有长度求和等于T。Sprite在加载阶段就绪；逐Tick不调用异步资源加载或SetSprite地址查询。优先用预载图集/资源绑定把Sprite对象缓存到View；具体加载归项目资源适配层管理，不能散落Resources.Load。

`transitionFrames=2` 只生成尾部取消窗口 `[T-2,T)`，有合法转移才离开；不更改自然完成长度。切换图片、开启Hitbox和音效均依据同一个ActionFrame。

## 3. Motor 为位置唯一写者

输入移动、根位移、击退、导航请求只提交运动请求，不直接改Transform。建议优先级：强制位移/击退 → 动作运动策略 → 普通移动；速度最终由Motor处理碰撞后写入逻辑位置，View追随快照。

MovementPolicy 可取 Locked、InputScaled、RootCurve、Free；带转向限制、最大修正距离和速度。站位修正需要扫掠路径和最大偏移，不能为了命中瞬移到目标。追踪窗口关闭后锁定方向，避免前摇提示与实际攻击相反。

首版以2D根节点局部Hitbox曲线为权威；不依赖渲染骨骼更新后的Transform。扩展骨骼挂点时可在编辑期烘焙战斗挂点轨迹；若运行时读取骨骼，必须在查询前同步求值且明确碰撞确定性限制。

## 4. 根运动与镜像

导入根运动为每逻辑帧位移增量曲线；Motor决定最终位移，后端不能再应用第二次根运动。片段接缝检查位移和速度突变，建议发制作警告，不用未经约束的自动修正改变碰撞。

2D局部坐标约定 +X为朝前、+Y向上，转向通过朝向符号映射；框体偏移和角度必须一并镜像。避免通过负Scale导致尺寸负值或碰撞方向反转。单位缩放是否影响攻击距离必须配置，不能随视觉缩放改变战斗规则。

## 5. 暂停、退出与回池

冻结时保持逻辑姿态；渲染插值不能让攻击框提前走到下一帧。动作中断仅保留旧视觉姿态用于混合，其逻辑框已关。回池清播放状态、材质临时参数、尾迹、子特效、绑定句柄和异步generation。

拟新增 `Core/Battle/View/` 下 SpriteActionPresenter、AnimationClipPresenter、SpinePresenter（后两者后续）；Motor 放 `Core/Battle/Motion/`。首版只实现 Sprite 后端和单一2D运动适配，不先安装 Spine 或 Animancer。
