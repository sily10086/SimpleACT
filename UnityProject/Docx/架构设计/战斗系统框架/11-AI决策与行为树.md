# AI决策与行为树

日期：2026-10-25；v0.1。对应原文08/12，结合13的动作重入约束。

## 1. 四个问题四个系统

| 问题 | 系统 |
|---|---|
| 我看见/记得什么 | Perception与Blackboard |
| 现在想攻击、接近还是撤退 | BehaviourRunner/决策策略 |
| 当前状态允许做吗 | UnitFSM |
| 这次攻击具体选哪招，怎样衔接 | ActionGraph |

AI可以评估招式距离和威胁作为高层效用，但不得另写取消窗口执行器。所谓“AI只写节奏”是职责目标，不是禁止AI理解任何攻击成本。

## 2. 数据定义

AIStateDefinition：稳定stateId、typeId、参数schema、默认参数、节点种类、tickPolicy。原文className仅作为编辑器显示/迁移线索，导出时生成显式factory注册；运行期不做Type.GetType/反射实例化。

AITreeDefinition：treeId、rootNodeId、nodes、children范围、subtreeRef。节点拥有独立nodeId和局部参数，stateId是可复用定义。Runtime保存当前游标、Running任务、调用栈和挂起信息，不能放进共享SO。

Blackboard保存感知事实及记忆：targetHandle、lastKnownPosition、lastSeenTick、感知版本、导航结果。HP/耐力/phase/CD从UnitRuntime读只读快照。黑板键用生成枚举/稳定注册，不让任意字符串哈希绕过类型检查。

## 3. 执行语义

| 节点 | Success / Failure / Running |
|---|---|
| Selector | 首个Success或Running获选；全部Failure才Failure |
| Sequence | 每项成功才继续；任一Failure失败；Running停在当前项 |
| Condition | 纯查询，不能修改世界 |
| AttackTask | 提交一次命令，等待命令回执和ActionHandle结束 |
| MoveTask | 提交移动目标，按Motor结果判断到达/失败 |
| SubtreeCall | 压栈进入；完成弹栈；取消逐层清理 |
| RandomSelector | 进入时抽一次并保留选择，不每Tick重新抽 |

顶层 `Combat > Alert > Patrol > Idle` 保证无有效策略时有Idle；内部攻击Selector允许Failure，否则无法回退到接近目标。原文一级/二级/三级可用于编辑器分类，但应由NodeKind和端口约束描述实际能力，而非把可复用子树根强行绑死在等级数字。

## 4. 命令与动作回执

```text
AttackTask.Enter:
  commandId = Submit(AttackPrimitive)
  status = WaitingAcceptance

AttackTask.Tick:
  Rejected -> Failure(原因)
  Accepted(actionHandle) -> Running
  Completed(actionHandle) -> Success
  Cancelled(actionHandle) -> Failure/按策略重评估
```

仅“发Intent后一直Running”等不到何时结束。必须区分缓冲待接受、已执行、取消、超时和完成，不能依赖当前动画名称推测。

受击挂起策略保留目标记忆，但原动作已被取消；恢复时检查句柄、重新感知并从合适策略节点评估，不继续等待被清掉的动作。死亡直接终止树及子任务；不在AI恢复中复活单位。

## 5. 降频、事件唤醒和反应公平性

原文6Tick决策、3Tick感知可作为起点。按EntityId错峰，每Tick只处理部分单位；攻击执行仍由World每Tick推进。事件唤醒只设置dirty/wake标志，在下一指定AI阶段处理，不直接在事件监听里递归Tick树。

“立即唤醒”不代表怪物必须零延迟躲玩家攻击；反应延迟、感知距离、攻击承诺窗口是游戏规则。PhaseController不需要等待6Tick才能发现已提交的阈值变化，可在P6标记下一Tick阶段迁移。

## 6. Boss阶段与固定派生

首次起手允许权重随机，链内auto边固定；怒态改变可用边/覆盖参数，疲劳改变已声明的速度/冷却，不默认重建全部动作图。阶段请求只产生一次，记录已触发阈值，避免HP在阈值附近反复切换。转阶段是否无敌与是否取消弹丸属于配置。

expand调用图在导出时检查无环，运行时限深8作为保护；动作图合法连招回边与AI递归子树调用不是同一种环。Parallel扩展需资源声明：Move、Aim、Attack各输出通道不能互相覆盖，首版可不用通用Parallel。

## 7. 接入和验收

拟新增 `Core/Battle/AI/` 的AIContext、PerceptionSystem、BehaviourRunner、TaskRegistry、CommandReceiptStore。制作面板展示活跃路径、拒绝原因、感知版本、目标句柄和等待动作ID。
