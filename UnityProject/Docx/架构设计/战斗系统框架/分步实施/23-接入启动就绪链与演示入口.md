## 4. 具体执行任务

### 23.1 定位最小入口改动

- [ ] **做什么**：定位最小入口改动。
- **为什么**：将游戏启动永久写死为开战不利于之后接菜单。
- **怎么做**：在现有池准备成功后调用演示入口；保留开关或明确开发流程。
- **关键伪代码**：

```text
await ExistingPoolInitializationAndPrewarm()
if demoEnabled: await demoEntry.EnterAsync()
```

### 23.2 串联准备步骤

- [ ] **做什么**：串联准备步骤。
- **为什么**：世界运行不能领先资源和监听绑定。
- **怎么做**：按定义快照、表现资源、World、输入桥/结果桥、Ready、Start 执行。
- **关键伪代码**：

```text
LoadSnapshot -> PrepareViews -> CreateWorld -> AttachBridges -> Ready -> Start
```

### 23.3 处理退出与晚到完成

- [ ] **做什么**：处理退出与晚到完成。
- **为什么**：加载中退出后完成不能再次启动。
- **怎么做**：每次 Enter 分配 session token；await 后核对；失效释放本次产物，失败进入可重试状态。
- **关键伪代码**：

```text
prepared = await Prepare(token)
if !IsCurrent(token): prepared.Release(); return
StartPrepared(prepared)
```

## 5. 本步完整流程伪代码

```text
EnterAsync():
  create new session token
  state = Loading
  prepare content and views
  if token invalid: release acquired resources; return
  create and bind world
  state = Ready
  Start()
OnFailure:
  release only acquired resources
  report meaningful stage and resource ID
  do not enter Running
```
