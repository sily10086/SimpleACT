## 1. 目标与需求

建立与发射者当前动作分离的弹丸实体，支持高速移动、穿透和明确寿命。

- **R1**：弹丸有独立实例身份和命中账本，发射后默认不随动作取消消失。
- **R2**：源属性采用明确的发射快照/实时规则，首版推荐快照。
- **R3**：寿命时间域、穿透次数、阻挡销毁和同 Tick 移动规则显式配置。

## 4. 具体执行任务

### 18.1 消费发射命令

- [ ] **做什么**：消费发射命令。
- **为什么**：同帧重复求值不能生成两颗弹丸。
- **怎么做**：命令以 actionHandle+eventId 标记；P3 生成起点，推荐下一 Tick 开始移动，写入正式基线。
- **关键伪代码**：

```text
ConsumeSpawnOnce(action,eventId)
projectile.activationTick = currentTick + 1
```

### 18.2 实现扫掠与穿透

- [ ] **做什么**：实现扫掠与穿透。
- **为什么**：只检测终点可能跳过薄目标。
- **怎么做**：使用前后位置扫掠；沿路径稳定排序，处理阻挡与目标，穿透额度按有效命中消耗。
- **关键伪代码**：

```text
contacts = Sweep(previous, next).SortBy(pathFraction, stableTargetId)
ProcessUntilPierceBudgetOrBlockingWall()
```

### 18.3 统一销毁与表现解绑

- [ ] **做什么**：统一销毁与表现解绑。
- **为什么**：回池不能直接决定逻辑寿命。
- **怎么做**：到期/碰墙/命中预算耗尽只走一次销毁；发 ProjectileRemoved 供视图桥处理。
- **关键伪代码**：

```text
if expired || blocked || exhausted: RemoveOnce(projectile)
```

## 6. 边界与失败处理

- 发射者死亡后不再从其运行数据读已失效属性；来源身份仍可保留用于归因。
- 弹丸激活时点属于提案细化，执行前同步配置规格，不默认为现有实现。
