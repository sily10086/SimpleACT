## 1. 目标与需求

让 Motor 统一处理移动、闪避、击退与阻挡，输出供命中使用的运动前后姿态。

- **R1**：逻辑位置仅由 Motor 写入，动画和输入只提供请求。
- **R2**：区分主动位移、动作位移、强制位移及冻结。
- **R3**：首版查询后端遵循已选 2D/确定性基线，不依赖 Unity 自动物理顺序。

## 4. 具体执行任务

### 14.1 定义写入权和优先级

- [ ] **做什么**：定义写入权和优先级。
- **为什么**：RootMotion 与输入同时改 Transform 会互相覆盖。
- **怎么做**：强制位移、动作位移、自由移动按基线优先级选取；锁定动作允许配置朝向变化。
- **关键伪代码**：

```text
desiredMotion = Arbitrate(forced, action, locomotion, permission)
```

### 14.2 执行阻挡与姿态提交

- [ ] **做什么**：执行阻挡与姿态提交。
- **为什么**：命中需要真实经过的空间区间。
- **怎么做**：保存 prevPose；扫掠阻挡裁剪位移；一次性写 nextPose，再生成渲染快照。
- **关键伪代码**：

```text
prev = unit.pose
actualDelta = geometry.SweepAndClip(prev, desiredDelta)
unit.pose = prev + actualDelta
```

### 14.3 接入冻结与闪避

- [ ] **做什么**：接入冻结与闪避。
- **为什么**：闪避遇墙不应重置动作计时。
- **怎么做**：冻结时不给主动位移积分；遇墙只裁剪位移，ActionFrame 仍按时间域推进。
- **关键伪代码**：

```text
if unitFrozen: output stationaryPose
else MoveWithCollision(); KeepActionClockIndependent()
```

## 5. 本步完整流程伪代码

```text
P3(unit):
  previousPose = unit.pose
  motion = ResolveMotionRequests(unit)
  if not motionClockAllowed: motion.delta = 0

  CommitPoseAndFacing(clipped)
  output {previousPose, currentPose, contacts}

```
