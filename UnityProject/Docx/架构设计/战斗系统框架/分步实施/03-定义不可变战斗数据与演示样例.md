## 1. 目标与需求

形成能驱动运行时的最小数据模型，并提供无需编辑器即可使用的 A/B/闪避样例。

- **R1**：定义与运行实例分开，窗口统一为 [start,end)。
- **R2**：覆盖动作、节点、边、命中组、伤害、视图绑定及单位基础定义。
- **R3**：样例使用 16 文档数值，标为开发数据，不伪装 Luban 生成物。

## 4. 具体执行任务

### 03.1 拆分编辑输入与运行定义

- [ ] **做什么**：拆分编辑输入与运行定义。
- **为什么**：编辑器的可修改列表不能在战斗中被随意改写。
- **怎么做**：输入 DTO 可变；冻结时复制数组并校验引用，对外只读访问。
- **关键伪代码**：

```text
sourceDto -> Validate -> CopyAndIndex -> ReadOnlySnapshot
```

### 03.2 定义时间轴与动作图关联

- [ ] **做什么**：定义时间轴与动作图关联。
- **为什么**：节点和动作并非一一对应，同动作可能在不同连招位置使用。
- **怎么做**：nodeId 引用 actionStableId；window、hitGroup、command 都带稳定 ID；不以数组位置作为持久引用。
- **关键伪代码**：

```text
GraphNode = { nodeId, actionStableId }
Window = { windowId, startFrame, endFrame, kind }
```

### 03.3 构建演示数据

- [ ] **做什么**：构建演示数据。
- **为什么**：先打通逻辑闭环，避免等待整套制作工具。
- **怎么做**：配置 A24/B30/Dodge18 和取消窗口，声明 Sprite 资源引用但不在构建器加载资源。
- **关键伪代码**：

```text
A = Action(24, hit:[6,10), cancelAttack:[14,20), cost:10)
B = Action(30, hit:[8,12), cost:15)
Dodge = Action(18, invulnerable:[2,8), cost:20)
```

BuildDemoDefinitions():

## 6. 边界与失败处理

- totalFrames<=0、窗口倒置或越界均为内容错误。
- 首版速度为 1，不偷偷加入浮点跳帧支持。
