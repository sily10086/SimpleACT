## 1. 目标与需求

把部位命中扩展为耐久、一次性破坏、后续倍率变化及表现通知，避免当前一击重复扣伤害。

- **R1**：部位选择先于伤害计算；每个部位具有 stableId、priority、耐久与破坏后行为。
- **R2**：当前击使用破坏前倍率，下一批接触再读取新状态。
- **R3**：PartBroken 只发一次；破坏不自动产生第二份 HP 伤害。

## 4. 具体执行任务

### 30.1 绑定几何部位与规则

- [ ] **做什么**：绑定几何部位与规则。
- **为什么**：Hurtbox 名称不能隐含倍率。
- **怎么做**：用 partId 关联定义；护甲 priority10、身体0，缺失部位引用阻止创建。
- **关键伪代码**：

```text
hurtbox.partId -> partRuntime -> definition
```

### 30.2 提交耐久与破坏

- [ ] **做什么**：提交耐久与破坏。
- **为什么**：两击同帧都把耐久减到零不能发两次破坏。
- **怎么做**：先按批次快照计算伤害，再聚合耐久变化；Active→Broken 只过一次。
- **关键伪代码**：

```text
old = durability
new = max(0, old - partDamageSum)
if old>0 && new==0 && !broken: CommitBreakOnce()
```

### 30.3 应用后续规则

- [ ] **做什么**：应用后续规则。
- **为什么**：破坏视觉和逻辑变化不能分散到多个回调。
- **怎么做**：提交时写 broken 状态、下一批倍率/禁用行为，发布结果供 View 处理。
- **关键伪代码**：

```text
part.broken = true
nextSnapshot.multiplier = brokenMultiplier
EmitPartBroken()
```

## 6. 边界与失败处理

- 同一 Tick 的多个接触都依据批次快照，不能后一击突然读取刚破坏的倍率。
- 部位移除后几何变化在下一收集阶段生效，不能修改正在遍历的候选集合。
