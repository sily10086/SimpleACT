## 1. 目标与需求

建立可由宿主显式推进的 60Hz 战斗时钟，并区分世界、单位、动作与表现时间。

- **R1**：SimTick 不跳号；窗口和动作事件逐逻辑步处理。
- **R2**：暂停清积压；局部冻结的解除由 SimTick 驱动。
- **R3**：首版最大补步 4、积压 4 为待测配置，不作为性能保证。

## 4. 具体执行任务

### 05.1 实现宿主累积调度

- [ ] **做什么**：实现宿主累积调度。
- **为什么**：渲染帧率不能决定每招实际帧数。
- **怎么做**：用固定间隔消费累积值；限制宿主时间债务并发 Overload 诊断，不直接增加 SimTick 跳过事件。
- **关键伪代码**：

```text
while accumulator >= step && count < maxSteps:
  ExecuteOneTick(); accumulator -= step; count++
```

### 05.2 定义冻结与恢复

- [ ] **做什么**：定义冻结与恢复。
- **为什么**：使用被冻结的 UnitTick 判断解除会永久冻结。
- **怎么做**：冻结结束存 SimTick；多个来源明确采用结束时间合并或独立来源表，不随意覆盖。
- **关键伪代码**：

```text
frozen = any activeFreeze where SimTick < endSimTick
advanceUnit = !frozen
```

### 05.3 处理暂停和插值

- [ ] **做什么**：处理暂停和插值。
- **为什么**：恢复时补跑暂停时间会导致瞬间战斗结算。
- **怎么做**：暂停时清 accumulator，恢复重新积累；表现插值只读，不推进逻辑。
- **关键伪代码**：

```text
if paused: accumulator = 0; return
alpha = Clamp01(accumulator / step)
```

## 5. 本步完整流程伪代码

```text
OnHostDelta(dt):
  if globallyPaused: accumulator = 0; return
  accumulator += dt
  repeat while enoughTime and withinStepBudget:
    ResolveFreezeExpiry(SimTick)
    stepContext = BuildTimeDomainContext(SimTick)
    world.Step(stepContext)
    SimTick++
    accumulator -= fixedStep
  ClampDebtAndRecordOverload()
  return RenderAlpha()
```
