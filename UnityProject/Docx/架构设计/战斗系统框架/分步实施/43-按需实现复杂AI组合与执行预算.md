## 4. 具体执行任务

### 43.1 定义组合结果契约

- [ ] **做什么**：定义组合结果契约。
- **为什么**：相同 Parallel 名称可能有不同结束语义。
- **怎么做**：逐节点定义 Success/Failure/Running 与取消剩余节点，使用注册工厂而非任意反射类名。
- **关键伪代码**：

```text
ThresholdReached -> CancelRemainingChildren -> ReturnAggregateResult
```

### 43.2 实现有界调度

- [ ] **做什么**：实现有界调度。
- **为什么**：服务与展开会放大一帧工作量。
- **怎么做**：独立计算服务到期；统计节点访问数和展开深度，超限诊断包含 nodeId。
- **关键伪代码**：

```text
if ++visited > budget: HaltWithDiagnostic(nodeId)
if expandDepth > 8: reject
```

### 43.3 清理节点拥有的等待

- [ ] **做什么**：清理节点拥有的等待。
- **为什么**：恢复 AI 不能继续等待已被取消的动作。
- **怎么做**：保存各节点 CommandId/ActionHandle；停止时撤销可撤销待执行命令，清游标；已执行动作按共同取消政策处理。
- **关键伪代码**：

```text
StopNode -> CancelOwnedPendingCommand -> ClearReceiptWait -> ExitOnce
```
