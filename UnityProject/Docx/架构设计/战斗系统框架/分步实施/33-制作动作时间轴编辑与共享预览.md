版本：v0.1｜阶段：S6｜状态：方案已编写，实施未开始。

## 1. 目标与需求

让策划在一个动作编辑窗口里设置阶段、取消窗口、命中框和命令，并使用运行时同语义预览。

- **R1**：首版优先 Sprite、单主通道和速度 1，不一次实现全部混合能力。
- **R2**：编辑源支持 Undo/Redo、稳定 ID 和保存。
- **R3**：预览无战斗副作用，不能播放预览就修改真实 HP 或生成持久实体。

## 4. 具体执行任务

### 33.1 实现基础编辑交互

- [ ] **做什么**：实现基础编辑交互。
- **为什么**：时间轴必须能制作规则，不只是显示曲线。
- **怎么做**：支持添加/移动/缩放区间、编辑 hitGroup、复制动作并生成新源 ID，使用 Unity Undo。
- **关键伪代码**：

```text
RecordUndo(source)
EditSelectedTrackRange()
MarkSourceDirty()
```

### 33.2 复用逻辑求值

- [ ] **做什么**：复用逻辑求值。
- **为什么**：另写一套预览窗口判断容易与运行时偏一帧。
- **怎么做**：同一纯求值器读取编译预览数据；Seek 重建只读预览状态，副作用发往模拟接收器。
- **关键伪代码**：

```text
previewSnapshot = evaluator.Sample(compiledPreview, frame)
previewSink.DrawOnly(previewSnapshot)
```

### 33.3 清理预览环境

- [ ] **做什么**：清理预览环境。
- **为什么**：切换资产或关窗后预览对象可能残留。
- **怎么做**：窗口持有预览资源 scope，切换/关闭时 Dispose；不注册真实 BattleModule。
- **关键伪代码**：

```text
OnSelectionChanged -> DisposePreviousPreview()
OnDisable -> DisposePreviewScope()
```

## 5. 本步完整流程伪代码

```text
OpenAction(source):
  create isolated preview
  compile in-memory preview DTO
Edit:
  record Undo and modify source
  show inline diagnostics
Seek(frame):
  evaluate shared timeline semantics
  draw sprite, hitboxes and active windows
Export:
  invoke compiler, never serialize UI state
```

## 6. 边界与失败处理

- 跳帧预览需要重建状态，不能真实重播所有伤害事件。
- 3D/Spine 轨道先显示能力不支持，直到对应适配完成。
