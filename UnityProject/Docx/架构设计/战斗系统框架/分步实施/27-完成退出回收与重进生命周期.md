## 1. 目标与需求

让战斗在正常退出、加载失败、加载中取消和快速重进时都能释放自身资源，建立基础切片的完整生命周期。

- **R1**：先停止输入和驱动，再清理异步任务、桥、视图与资源。
- **R2**：清理可重复调用，不重复 Despawn/卸载。
- **R3**：全局对象池和其他模块资源不由本场关闭。

## 4. 具体执行任务

### 27.1 关闭新增工作入口

- [ ] **做什么**：关闭新增工作入口。
- **为什么**：清资源时仍推进 Tick 会重新创建对象。
- **怎么做**：立即禁止 Submit，移除更新监听，递增会话代次并取消等待。
- **关键伪代码**：

```text
acceptCommands=false; RemoveDriver(); InvalidateSession(); CancelPendingWork()
```

### 27.2 回收本场持有内容

- [ ] **做什么**：回收本场持有内容。
- **为什么**：各种退出原因必须走同一生命周期。
- **怎么做**：解绑事件/HUD、取消表现、Unbind View、Despawn 实例、释放租约、清 World，记录各阶段已执行。
- **关键伪代码**：

```text
Detach -> Unbind -> DespawnOwned -> ReleaseOwned -> ClearWorld
```

### 27.3 处理晚到完成与重进

- [ ] **做什么**：处理晚到完成与重进。
- **为什么**：异步取消不是资源自动释放保证。
- **怎么做**：旧 token 回调归还自己的结果，不访问新会话 scope；新场分配新 BattleId。
- **关键伪代码**：

```text
if completion.token != activeToken: completion.Release(); return
```

## 5. 本步完整流程伪代码

```text
Stop(reason):
  if already disposed: return
  disable Submit and Step
  unregister driver once
  invalidate tokens and cancel waits
  detach result/input/UI bridges
  unbind and reclaim session views
  release only session-owned resource leases
  clear world and mark Disposed
NewEnter:
  allocate a fresh BattleId and independent scope
```
