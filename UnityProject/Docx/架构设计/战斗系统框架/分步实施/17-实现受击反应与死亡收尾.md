## 1. 目标与需求

将一批伤害事实收敛为每单位唯一的优先反应，并统一硬直、破韧、击退和死亡。

- **R1**：死亡优先于破韧和普通受击；相同优先级有稳定规则。
- **R2**：霸体阻止普通硬直，默认不阻止 HP 和削韧。
- **R3**：死亡与动作终止只发布一次，状态推进遵循 UnitTick。

## 4. 具体执行任务

### 17.1 合并反应

- [ ] **做什么**：合并反应。
- **为什么**：多次命中不能反复重播低优先级受击覆盖死亡。
- **怎么做**：按死亡、破韧、其他强制、普通受击决策；硬直延长/替换明确写规则。
- **关键伪代码**：

```text
winner = DeathIfHPZero ?? PoiseBreak ?? HighestAllowedReaction
```

### 17.2 提交状态与取消

- [ ] **做什么**：提交状态与取消。
- **为什么**：伤害后旧攻击继续运行会产生幽灵命中。
- **怎么做**：P6 调用统一取消，再迁移状态、提交 Motor 强制请求；不回到同 Tick P3。
- **关键伪代码**：

```text
CancelCurrent(winner.reason)
State.Commit(winner)
Motor.QueueForcedMotionForNextExecution()
```

### 17.3 结束硬直与死亡清理

- [ ] **做什么**：结束硬直与死亡清理。
- **为什么**：Poise 何时恢复和 AI 何时重新决策需要一致。
- **怎么做**：破韧 20 UnitTick 结束恢复 Poise；死亡标记一次，通知后续 Buff/AI/View 清理。
- **关键伪代码**：

```text
if breakStunExpired && !dead: restore maxPoise; enter Active
if newlyDead: EmitUnitDiedOnce()
```

## 5. 本步完整流程伪代码

```text
P6(unit):
  facts = batchFacts.For(unit)

```
