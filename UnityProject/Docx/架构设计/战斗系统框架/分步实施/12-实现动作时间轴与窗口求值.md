## 1. 目标与需求

把动作定义转换为每 Tick 的窗口状态、命令与表现快照，建立所有动画后端共用的逻辑时间轴。

- **R1**：frame0 必须执行且仅执行一次；有效帧索引为 0..duration-1。
- **R2**：窗口采用半开区间，暂停/冻结不补发事件。
- **R3**：P6 新受击动作的安全初始化不能同 Tick 再产生攻击。

## 4. 具体执行任务

### 12.1 实现窗口函数

- [ ] **做什么**：实现窗口函数。
- **为什么**：边界不统一会导致额外一帧无敌或漏掉取消。
- **怎么做**：纯函数 IsActive(frame,start,end)，派生属性不靠 AnimationEvent 开关。
- **关键伪代码**：

```text
active = start <= localFrame && localFrame < end
```

### 12.2 防止事件重复与遗漏

- [ ] **做什么**：防止事件重复与遗漏。
- **为什么**：起手与执行阶段都能接触 frame0。
- **怎么做**：保存 evaluatedFrame 或事件游标；P2 只登记初始化，P3 统一执行攻击相关命令。
- **关键伪代码**：

```text
if cursor.evaluatedFrame != frame:
  EmitCommandsAt(frame); cursor.evaluatedFrame = frame
```

### 12.3 处理自然结束与反应初始化

- [ ] **做什么**：处理自然结束与反应初始化。
- **为什么**：新反应不应在 P6 重新进入碰撞。
- **怎么做**：P7 推进前区分本 Tick P2 与 P6 创建实例；P6 创建实例保留 frame0 到下一 Tick P3。
- **关键伪代码**：

```text
if createdDuringP6: keep frame0
else if advanced: localFrame++
if localFrame == duration: complete at next prepare boundary
```

## 6. 边界与失败处理

- 这是对原阶段约定的执行细化：P2 起手当 Tick 可执行 f0，P6 起手下 Tick 才执行 f0。
