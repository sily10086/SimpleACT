## 2. GitHub 调研范围

详细仓库链接、用途、依赖、局限及选型结论见 [15 GitHub 十四项目调研](15-GitHub十四项目调研与选型.md)。本次读取了 14 个独立仓库的元信息及 README，并进一步阅读部分关键源文件：

- EGamePlay：`AbilityExecution.cs`，用于理解能力定义与运行实例的分离。

- NodeGraphProcessor：`BaseGraph.cs`，用于观察节点、边、标识与图数据结构。

本次没有安装、运行、完整审计或复制这些框架。仓库成熟程度、目标规模与维护状态不能单独证明适配本项目；许可证与商业依赖在调研文档中分别注明，未来引入具体版本时仍应按该版本核对。文档中的选型以借鉴职责划分和机制为主，不预设采购或引入整套框架。
