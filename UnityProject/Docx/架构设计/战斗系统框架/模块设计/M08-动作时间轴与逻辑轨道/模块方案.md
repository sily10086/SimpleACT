# M08 动作时间轴与逻辑轨道：分析、完善与制作方案

日期：2026-10-25｜方案版本：v0.2｜实现状态：未开始。模块编号表示功能归属，不表示全局开发步骤。

## 1. 模块是什么，解决什么问题

定义并求值一招的每个时刻：何时可取消、何时开启攻击框、何时无敌、何时发射和移动。

**负责的内容**：ActionFrame、相位/窗口/事件轨道、命令游标、逻辑求值、后端无关动作快照。

**边界**：不选择下一招，不控制骨骼/贴图细节，不直接扣血；素材播放属于 M16。

## 2. 原设计分析与需要完善的地方

- 原文把复合动画当第一等内容有价值，但统一 JSON 不等于统一所有骨骼播放能力。
- frame0、跳帧、半开窗口和取消后事件清理未形成完整契约。

## 3. 完善后的设计

UAnim 统一外层逻辑时间轴；求值输出命令和只读窗口。首版速度1，区间统一 [start,end)。P2 起手当 Tick P3 执行 f0；P6 新反应保留 f0 至下一 Tick，避免 P7 提前自增。

| 本模块拥有的数据 | 用途及写入规则 |
|---|---|
| ActionDefinition 轨道 | 只读 phase/window/command/viewTrack。 |
| TimelineCursor | 已求值帧/事件游标，按动作实例隔离。 |
| WindowSnapshot | 当前帧派生值，不由动画回调手动开关。 |

## 4. 对外接口与协作边界

| 拟新增契约 | 输入与输出、调用时点 |
|---|---|
| `Evaluate(action, tickContext)` | 输出本帧窗口、运动/攻击/弹丸命令。 |
| `GetWindows(definition, frame)` | 纯查询，可供 M07 在 P2 使用。 |
| `SamplePreview(definition, frame)` | 无副作用求值，供编辑器复用。 |

**依赖关系**：M06 提供当前实例，M01 提供时间域；输出由 M09/M10/M14 接收，M16 只读表现轨道。

**如何单独制作**：固定动作定义+人工局部帧+记录命令的 sink 即可制作，资源可以为空。

以上为拟新增契约，不是项目现有 API。先固定输入输出，再替换开发替身为真实相邻模块；替身只用于模块开发，不代表整个战斗已集成。

## 5. 本模块内部的制作步骤

### M08.1 制作轨道 Schema 与窗口函数

- [ ] **目标与需求**：统一边界避免差一帧。
- **涉及内容与做法**：轨道带稳定 ID、类型及参数；所有时长可静态校验。
- **关键伪代码**：

```text
active = start<=frame && frame<end
```

### M08.2 制作游标与一次性命令

- [ ] **目标与需求**：frame0 不漏且不重复。
- **涉及内容与做法**：P2 登记起手，P3 单次执行；冻结不推进游标。
- **关键伪代码**：

```text
if frame!=evaluatedFrame:
  EmitCommandsAt(frame); evaluatedFrame=frame
```

### M08.3 制作预览端口与扩展约束

- [ ] **目标与需求**：制作工具复用逻辑，不另写规则。
- **涉及内容与做法**：预览只输出描述；倍率作为后续独立能力，需要跨区间扫掠。
- **关键伪代码**：

```text
previewSink.Draw(EvaluatePure(frame))
Cancel -> invalidate future source commands
```
