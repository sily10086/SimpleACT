# M19 动作时间轴制作工具：分析、完善与制作方案

日期：2026-10-25｜方案版本：v0.2｜实现状态：未开始。模块编号表示功能归属，不表示全局开发步骤。

## 1. 模块是什么，解决什么问题

让策划独立制作一招的阶段、窗口、框体、位移与表现轨道，并准确看到逻辑时刻。

**负责的内容**：时间轴窗口、轨道编辑、属性面板、Undo/Redo、隔离预览、错误定位。

**边界**：不承担动作图连线，不在工具里重新实现战斗求值；不直接生成/发布整套资源包。

## 2. 原设计分析与需要完善的地方

- 原文编辑器内容丰富，但一次支持所有混合/遮罩/三后端成本过高。
- 预览若另写窗口算法容易与运行偏帧，工具应复用 M08 的纯求值能力。

## 3. 完善后的设计

先支持 Sprite、速度1、单主动作轨道。Authoring DTO 可编辑，运行 DTO 不直接作为界面状态。编辑记录 Undo，预览调用 M08 并把副作用送模拟 sink，导出交 M21。

| 本模块拥有的数据 | 用途及写入规则 |
|---|---|
| ActionAuthoring | 稳定 ID、轨道与资源引用。 |
| EditorSelection / Undo | 仅编辑器持有，不导出。 |
| PreviewSession | 预览对象和资源 scope。 |

## 4. 对外接口与协作边界

| 拟新增契约 | 输入与输出、调用时点 |
|---|---|
| `OpenAction(source)` | 载入编辑源和隔离预览。 |
| `Seek(frame)` | 纯求值绘制当前窗口/框体。 |
| `RequestCompile(source)` | 交 M21 校验和编译。 |

**依赖关系**：使用 M08 求值、M16 预览适配和 M21 编译端口；无需 M07/M15 先完成。

**如何单独制作**：给一个静态 A 动作和 Sprite 素材就可制作窗口编辑与预览，不必先运行整场战斗。

以上为拟新增契约，不是项目现有 API。先固定输入输出，再替换开发替身为真实相邻模块；替身只用于模块开发，不代表整个战斗已集成。

## 5. 本模块内部的制作步骤

### M19.1 制作编辑源与基础面板

- [ ] **目标与需求**：能实际编辑字段而非只画时间尺。
- **涉及内容与做法**：动作列表、时间尺、轨道、属性区域；修改记录 Undo 和 dirty。
- **关键伪代码**：

```text
RecordUndo(source); EditTrack(); MarkDirty()
```

### M19.2 制作窗口与框体编辑

- [ ] **目标与需求**：将战斗规则直观表达。
- **涉及内容与做法**：支持移动/缩放区间、hitGroup/part引用，边界即时诊断。
- **关键伪代码**：

```text
DragRange -> UpdateSourceInterval -> ShowValidation()
```

### M19.3 制作共享预览与释放

- [ ] **目标与需求**：预览不产生真实伤害和残留。
- **涉及内容与做法**：隔离 Session，Seek 重新构建预览状态；关闭释放所有预览持有对象。
- **关键伪代码**：

```text
PreviewSink.Draw(Timeline.Sample(frame))
Close -> DisposePreviewScope()
```

**独立交付物**：能制作并预览一招的工具窗口与源资产。

## 7. 一个具体例子与完成标准

策划把 A 有效窗口从 [6,10) 拖为 [5,9)，预览在5亮框、9关闭；导出后同一时间轴定义被运行时读取。

- [ ] Undo/Redo 恢复规则与引用。
- [ ] 预览无真实战斗副作用。
- [ ] 导出不包含面板选中/缩放状态。

这些是未来完成标准，本次没有运行检查；只有实际完成实现后才勾选。
