# M13 受击部位与破坏：分析、完善与制作方案

日期：2026-10-25｜方案版本：v0.2｜实现状态：未开始。模块编号表示功能归属，不表示全局开发步骤。

## 1. 模块是什么，解决什么问题

让头、身体、护甲等部位具有独立命中规则、耐久和破坏后行为，支持局部弱点与阶段触发。

**负责的内容**：PartDefinition/Runtime、部位优先级、倍率查询、耐久变化、破坏一次性状态与结果。

**边界**：不做几何收集、不独立计算整份伤害，不在破坏监听中直接发掉落奖励。

## 2. 原设计分析与需要完善的地方

- 原文提到部位 HP/倍率，但缺少同组多部位选择与破坏时机。
- 破坏前/后的当前击倍率不明确会产生重复伤害或同帧顺序差异。

## 3. 完善后的设计

Hurtbox 仅引用 partId；M10 选部位，M11 读取批次快照倍率并提交部位伤害。本模块聚合耐久变化、从 Active 过渡到 Broken 一次，下一批几何/倍率读取新状态。

| 本模块拥有的数据 | 用途及写入规则 |
|---|---|
| PartRuntime | remainingDurability、broken、一次性结果标志。 |
| PartDefinition | priority、倍率、破坏后可命中性与反应。 |
| PartSnapshot | 本批可读状态，结算期间冻结。 |

## 4. 对外接口与协作边界

| 拟新增契约 | 输入与输出、调用时点 |
|---|---|
| `GetPartSnapshot(actor)` | 供 M10/M11 查询选择/倍率。 |
| `ApplyPartDamage(batch)` | 由 M11 P5 提交。 |
| `GetBrokenVariant(partId)` | 只读表现变体标识，M16/M17 消费。 |

**依赖关系**：依附 M02 实体，输入 M11 部位伤害；输出事实给 M05/M17；不拥有角色总 HP。

**如何单独制作**：直接给定部位伤害序列，不需要模型和真实框体，即可制作耐久与一次性破坏。

以上为拟新增契约，不是项目现有 API。先固定输入输出，再替换开发替身为真实相邻模块；替身只用于模块开发，不代表整个战斗已集成。

## 5. 本模块内部的制作步骤

### M13.1 制作部位定义与绑定

- [ ] **目标与需求**：几何名称不隐含玩法规则。
- **涉及内容与做法**：用稳定 partId 关联 Hurtbox，缺引用拒绝内容。
- **关键伪代码**：

```text
hurtbox.partId -> PartDefinition -> PartRuntime
```

### M13.2 制作耐久和破坏事务

- [ ] **目标与需求**：同批多击不能重复破坏。
- **涉及内容与做法**：聚合本批耐久变化，跨零时一次性提交；保留当前批倍率快照。
- **关键伪代码**：

```text
new=max(0,old-sumDamage)
if old>0 && new==0: BreakOnce()
```

### M13.3 制作破坏后能力与通知

- [ ] **目标与需求**：破坏不是仅换贴图。
- **涉及内容与做法**：配置新倍率、框启用、反应请求和表现变体；下批读取。
- **关键伪代码**：

```text
CommitBrokenState()
EmitPartBroken(variant, reactionRequest)
```
