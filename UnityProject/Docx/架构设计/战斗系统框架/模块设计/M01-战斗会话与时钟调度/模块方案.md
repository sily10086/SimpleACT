# M01 战斗会话与时钟调度：分析、完善与制作方案

日期：2026-10-25｜方案版本：v0.2｜实现状态：未开始。模块编号表示功能归属，不表示全局开发步骤。

## 1. 模块是什么，解决什么问题

管理一场战斗从准备到释放的生命周期，并给所有逻辑提供同一个执行时间和阶段顺序。它是组装者，不承载技能规则。

**负责的内容**：BattleModule、BattleWorld 调度、SimTick/UnitTick、暂停冻结、会话生命周期、阶段缓冲拥有关系。

**边界**：不解析连招、不计算伤害、不实现具体动画；只按已定义契约调度这些模块。时钟为内部独立组件，不为每单位注册 Update。

## 2. 原设计分析与需要完善的地方

- 原文强调 60 帧，但混用了渲染帧、固定步和动作帧；需要四类时钟和卡顿策略。
- 原文清空事件的方案没有区分未执行命令与已提交结果；会话必须分别管理。
- 当前项目物理步长 0.02，现有 UpdateDriver 可复用；60Hz 战斗不能直接假定由当前 FixedUpdate 提供。

## 3. 完善后的设计

BattleModule 负责加载/开始/退出，BattleClock 产生步预算，BattleWorld 负责 P0–P7。各系统被显式调用，模块间结果通过受控阶段传递。首版速度 1，每渲染帧最多补 4 步、最多保留 4 步债务是提案配置。暂停清宿主债务，局部冻结结束使用 SimTick。

| 本模块拥有的数据 | 用途及写入规则 |
|---|---|
| SessionState / BattleId | 会话创建者分配；Ready 才允许 Start。 |
| SimTick / accumulator | Clock 唯一写入；不跳号丢动作事件。 |
| 阶段命令与结果缓冲 | 待执行命令可失效；已提交结果不可撤回。 |

## 4. 对外接口与协作边界

| 拟新增契约 | 输入与输出、调用时点 |
|---|---|
| `PrepareAsync(snapshot, resources)` | 组装依赖，成功产出 Ready 会话。 |
| `Advance(hostDelta)` | 驱动 0..N 个固定逻辑步，返回渲染插值。 |
| `Stop(reason)` | 先禁输入/解绑驱动，再按拥有关系释放。 |

**依赖关系**：依赖 M18 提供已准备内容，持有 M02–M17 的实例并调度；各领域模块不反向获取 GameModule.Battle。

**如何单独制作**：使用记录调用顺序的空系统和人工 delta，可先制作调度与会话状态；无需玩家、敌人或美术。

以上为拟新增契约，不是项目现有 API。先固定输入输出，再替换开发替身为真实相邻模块；替身只用于模块开发，不代表整个战斗已集成。

## 5. 本模块内部的制作步骤

### M01.1 制作会话状态与装配入口

- [ ] **目标与需求**：每次创建/退出有明确状态与身份。
- **涉及内容与做法**：新增 BattleModule/BattleWorld 构造入口，依赖显式传入。
- **关键伪代码**：

```text
Prepare -> Ready -> Start -> Running
Stop -> Stopping -> Disposed
```

### M01.2 制作时钟和阶段执行

- [ ] **目标与需求**：一个宿主驱动产生稳定逻辑步骤。
- **涉及内容与做法**：先做纯 Clock，再将各系统挂到 P0–P7 固定位置；禁止 Step 重入。
- **关键伪代码**：

```text
while debt>=step && count<budget:
  world.Step(simTick); simTick++; debt-=step
```

### M01.3 制作暂停与释放

- [ ] **目标与需求**：快速进入退出不残留驱动和晚到任务。
- **涉及内容与做法**：采用会话 token、同步注册的 UpdateDriver 门面；所有释放只操作本场资源。
- **关键伪代码**：

```text
DisableSubmit -> RemoveDriver -> InvalidateToken -> ReleaseOwnedScopes
```

## 7. 一个具体例子与完成标准

输入 1/30 秒宿主 delta，在预算充足时应推进两次 60Hz Tick；暂停两秒再恢复不补跑这两秒。冻结敌人时世界 Tick 继续，因此冻结能如期解除。

- [ ] 仅一个战斗更新监听。
- [ ] 阶段固定，暂停/冻结时域明确。
- [ ] Stop 后异步完成不能重新启动旧场。

这些是未来完成标准，本次没有运行检查；只有实际完成实现后才勾选。
