# M14 弹丸与持续攻击实体：分析、完善与制作方案

日期：2026-10-25｜方案版本：v0.2｜实现状态：未开始。模块编号表示功能归属，不表示全局开发步骤。

## 1. 模块是什么，解决什么问题

管理已经发射后独立存在的攻击对象，让飞行、穿透、寿命和命中不依赖发射者当前动作。

**负责的内容**：弹丸实例、来源快照、激活时点、运动区间、穿透/阻挡、寿命与销毁。

**边界**：不自写伤害公式，不让对象池决定逻辑寿命；显示由 M16。

## 2. 原设计分析与需要完善的地方

- 原文的动作事件需要发射物承接，但其独立身份/存活规则没有展开。
- 只检测终点会穿过薄目标，取消动作就清掉所有弹丸也不符合默认发射语义。

## 3. 完善后的设计

Spawn 命令以动作实例+事件 ID 去重；弹丸有自己的攻击实例和账本，保存发射属性快照与来源身份。激活/寿命时域由配置声明；建议生成后下一 Tick 移动是待确认细化。扫掠候选仍进入 M10/M11。

| 本模块拥有的数据 | 用途及写入规则 |
|---|---|
| ProjectileRuntime | pose、velocity、activationTick、expire、pierceRemaining。 |
| SourceSnapshot | 发射者归因和伤害数据快照。 |
| AttackIdentity | 独立于发射动作的攻击来源与命中组。 |

## 4. 对外接口与协作边界

| 拟新增契约 | 输入与输出、调用时点 |
|---|---|
| `Spawn(command, sourceSnapshot)` | 消费一次发射命令。 |
| `Advance(context, geometry)` | 输出区间与候选攻击信息。 |
| `ApplyHitOutcome(outcome)` | 按有效命中更新穿透等状态。 |
| `Remove(reason)` | 统一销毁一次并通知 View。 |

**依赖关系**：接收 M08 命令，使用 M09 几何端口，交 M10/M11 命中结算；M01 负责时域推进。

**如何单独制作**：固定速度+直线查询替身+手工命中结果，就能完成寿命和穿透；无需发射动画。

以上为拟新增契约，不是项目现有 API。先固定输入输出，再替换开发替身为真实相邻模块；替身只用于模块开发，不代表整个战斗已集成。

## 5. 本模块内部的制作步骤

### M14.1 制作独立实例与快照

- [ ] **目标与需求**：发射者退出仍可归因。
- **涉及内容与做法**：源数据在发射时固定，按事件键去重。
- **关键伪代码**：

```text
if !consumed(action,event): CreateProjectile(snapshot)
```

### M14.2 制作运动与接触区间

- [ ] **目标与需求**：高速攻击不只检查终点。
- **涉及内容与做法**：按路径接触参数排序，墙体阻挡与目标都进入明确策略。
- **关键伪代码**：

```text
contacts=Sweep(prev,next).StableSortByPath()
ResolveUntilBlockedOrPierceExhausted()
```

### M14.3 制作寿命与移除

- [ ] **目标与需求**：任何销毁原因走同一出口。
- **涉及内容与做法**：时域到期、碰墙、预算耗尽移除一次，发布解绑结果。
- **关键伪代码**：

```text
if expired || blocked || exhausted: RemoveOnce()
```

## 7. 一个具体例子与完成标准

攻击动作在发射后被打断，已创建弹丸继续飞；发射前被打断则未来 Spawn 命令失效。

- [ ] 发射命令不重复生成。
- [ ] 发射者销毁不触发无效属性读取。
- [ ] 弹丸移除与视图归还最多一次。

这些是未来完成标准，本次没有运行检查；只有实际完成实现后才勾选。
