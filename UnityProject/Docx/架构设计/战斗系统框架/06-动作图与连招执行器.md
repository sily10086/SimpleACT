# 动作图与连招执行器

日期：2026-10-25；v0.1。对应原文 ABT。保留 ABT 作为业务称呼，但数据语义应称 ActionGraph：它不是标准 Selector/Sequence 行为树的同义词。

## 1. 三种身份必须分开

- ActionDefinitionId：一份可共享动作时间轴，如 slash_a。
- NodeId：某张动作图中的一个位置；两个节点可以引用同一动作，但拥有不同出边、覆盖参数。
- ActionInstanceId：一次实际施放，包含当前帧、命中记录、取消代次等。

复用配置不复用运行态。怪物和玩家可以引用同一个基础动作再选择覆盖数据，修改共享资产须显示引用者。

## 2. MVP 图模型

首版支持 Entry/Action/Selector/Exit 与带条件的 Edge；先实现单个主动作通道。原文 Composite 叶子改名 ActionNode，避免与 AI 的 Composite 组合节点混淆。

| Edge 字段 | 语义 |
|---|---|
| edgeId/fromNode/toNode | 稳定引用 |
| trigger | Intent / ActionCompleted / Auto / HitConfirmed |
| windowId | 引用源动作窗口；不存在则导出失败 |
| conditions | 地面、资源、phase、目标方位等纯查询条件 |
| priority | 候选排序，不取代权限检查 |
| weightGroup/weight | 同一显式随机组选取；不能把所有同优先级边都随机 |
| consumeIntent | 是否在动作成功提交后消费该命令 |
| requiredTags/blockedTags | 规则门控 |
| nextActionOverrides | 合法、有限的参数覆盖 |

同候选确定排序：priority 降序 → 条件特异度（若明确配置）→ edgeId 升序。随机仅在标记的权重组中调用 World 注入的随机流，记录种子与抽样次数。

## 3. 执行算法

```text
PrepareAction(unit):
  if UnitFSM禁止行动: return
  snapshot = 当前单位上下文
  candidates = 当前节点出边中触发、窗口、条件满足者
  按固定规则选出候选
  if 候选存在:
    TryStartAction事务；成功才消费Intent
  else if 当前动作结束:
    走Completion/Exit，否则回该状态默认动作
```

窗口开放只代表“允许”，不是自动取消。没有输入也没有 auto 边时，完整播放后摇。原文 transitionFrames 应导出为尾部取消窗口，不在 Sprite 播放器内暗中减总时长。

HitConfirmed 派生只能读取已提交命中，首版在下一 Tick 判定；需要同 Tick 追击时必须增加一个明确后结算阶段，不能在伤害监听器里直接递归 Play。

## 4. 环与子图

跨多个 Tick 的连招环可合法；同 Tick 的 Selector→Selector→Auto 环会卡死。导出时拒绝无耗时且无外部等待的强连通循环，运行时保留 MaxTransitionsPerTick 预算（演示8次），超限中止该图并记录路径。

图引用需显式 SubgraphCall/Return，记录调用栈、返回节点和局部参数；不能只写一个动画 ID 就认为天然拥有子图调用语义。首版可在导出阶段展开无环共享子图，保留来源路径用于调试。

## 5. 并行与 Decorator 的真实成本

Parallel 需要每通道游标、完成条件（全部/任一）、取消传播和资源写冲突裁决。首版采用 MainAction 与 Locomotion 的固定双职责协作；MainAction 提供 MovementPolicy，Motor 始终是位置唯一写者。后续上半身动作增加 UpperBody 通道，不允许两个动作同时写同一 RootMotion。

Decorator 若持有计数、冷却或等待，状态属于节点实例；不同单位不能共享。简单窗口/标签条件先编译成边条件，减少节点种类。保留扩展点不等于先写一套无限通用解释器。

## 6. 取消的统一语义

正常完成、主动取消、受击取消、死亡、目标丢失、场景退出都有 ActionEndReason。结束只执行一次，释放动作标签、运动占用、攻击命中集合和持续表现句柄。是否退款、保留子弹由动作规则决定：已发射弹丸默认独立生存，未发射命令作废。

拟新增 `Core/Battle/Action/ActionGraphRunner`、ActionRuntime、ActionCancelService、ConditionEvaluator。未来检查环超限、尾部窗口无输入不跳招、同动作不同节点独立派生、取消未提交事件不执行、共享定义不共享命中集。
