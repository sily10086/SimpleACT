# SimpleACT 角色动作、耐力与速度档

日期：2026-10-24；分析稿 v0.1。对应原文 §4.1–4.4、§4.6。依赖 03 的 Tick/单位/输入，冲突见 D01–D03、D09、D21、D30、D32。

## 1. 系统边界

RunModule 持有 CharacterMotorSystem、ActionSystem、StaminaSystem、SpeedTierSystem。PlayerState 是唯一运行真相，View 不扣耐力、不决定起跳/无敌/攻击帧。角色没有可成长血条，Alive 足够表达一击必杀。

建议状态采用两个正交维度：Locomotion（Grounded/Airborne）与 Action（None/Attack/Dodge），加 Dead/Exhausted 标记。避免把“空中攻击、地面攻击、空中闪避”等组合全部做成独立大状态。每次动作拥有 ActionId、frameIndex、phase、sourceInputId、successConsumed。

## 2. 动作规则与实际制作

| 功能 | 规则 | 实现与制作 |
|---|---|---|
| 水平移动 | 速度随档位改变，空中持续消耗 | Motor 根据方向与当前参数推进；速度/加速度/转向减速度分别配置，不拿动画 root motion 作真相 |
| 起跳 | 扣耐力，给垂直初速 | 只接受地面条件；落地边沿重置次数；离地状态只发一次 |
| 二段跳 | 空中次数大于0且耐力足够 | 成功后扣次数；重置到上限而非累加，不允许击杀多敌无限叠次数 |
| 蹬墙 | 沿墙法线反向弹射，同墙同次滞空仅一次 | 墙用稳定 wallId；需明确水平输入/接触阈值，落地清除已蹬墙集合；不重置二段跳 |
| 闪避 | 前半无敌、后半可受击；攻击互锁 | 帧索引采用半开区间；无敌长度/总长度来自配置，成功事件由战斗系统裁决 |
| 攻击 | 前摇、ACTIVE、后摇，后摇输入可缓冲 | Hitbox 随朝向翻转；逻辑帧启停，不依赖动画是否播放到帧 |

原文 px/s 转为世界单位需要 D30；不能把 400px/s 当 400 Unity units/s。重力、终端速度、跳跃上升时间、闪避方向/距离和是否冻结重力仍需补表。参考 [Tarodev](https://github.com/Matthew-J-Spencer/Ultimate-2D-Controller) 的输入缓冲思路与 [SebLague](https://github.com/SebLague/2DPlatformer-Tutorial) 的碰撞分层；土狼时间/跳跃截断不是原文已要求功能，不自动加入。

## 3. 耐力账本

动作成本由统一 EvaluateCost 计算：基础成本 × 档位消耗系数 × 装备修正，必要的整数舍入只做一次。是否所有主动动作都乘档位系数按原意推荐一致处理，不能移动优惠但攻击写死。

```text
TryStartAction(request):
  检查动作锁、环境、次数、档位支付能力
  cost = CostPolicy(action, tierBeforeAction, equipmentSnapshot)
  if stamina < cost: 返回 InsufficientStamina
  同一提交：stamina -= cost; tier -= tierCost; quota -= requiredQuota
  创建动作实例; 消费请求
```

tierCost 不足时建议拒绝技能而不是支付不够仍释放，这与原文“掉档最低0”不完全等价，必须在具体主动模组规格中确认。动作费用使用支付前档位，支付后更新能力和镜头目标。

所有回复通过同一个 AddStamina(reason, amount) 截断到上限；上限降低时当前值不超新上限。耗尽只在正数到0的边沿提示一次。拒绝动作不扣费、不扣次数、不推进连闪计数。

原文耗尽后自由落体直至落地，与中途升档回血冲突。D32 未确认前保留 Exhausted 锁存策略作为建议；是否解除由显式规则决定，不能仅用 stamina>0 偷偷恢复控制。

## 4. 升档与落地事务

airborneTicks 是连续滞空计数；每达到升档间隔只升一次，到上限不重复发奖励。另记录 sinceLastTierUpTicks，技能掉档后不能根据总 airTime 立即补回刚掉的档。

```text
OnLanded(islandId):
  speedTier = 0
  continuousAirTicks = 0; sinceLastTierUpTicks = 0
  jumpsLeft = configuredAirJumps; airDodgesLeft = configuredAirDodges
  wallJumpLock.Clear()
  BeginLandingRecovery(islandId, configuredTotal, configuredDuration)
  Commit(Landed, TierReset, QuotaReset)
```

落地只在空中→稳定支撑面边沿触发，OnStay 不重复领回复。岛侧面碰撞不是落地；撞顶也不算。上升穿平台是否允许是关卡碰撞规则，首版建议全实心平台，不默加单向平台。

落岛回复按 PlayerStep 或指定统一时钟分配整数累计值：本帧已发总量 = floor(total × elapsed / duration)，本帧增量取差值，防每帧舍入累计少给。离岛取消剩余；满耐力时溢出丢弃，不能存成隐藏补给。地刺接触不触发“安全落岛收益”。

## 5. 次数重置和连续闪避

重置途径：有效精准闪避、有效弹刀、击杀、有效普通闪避；落地自然补满。一次事件只执行 ResetToMax，绝不 ++。同一闪避最终分类只有一种，早期已精准成功则后半段不能再认普通成功。

连续闪避费用序列、上限策略、重置间隔进配置。原文序列用尽后怎么办未写，建议取最后一项封顶，需确认。仅在闪避真正被接受时推进 chainCount；失败按键不涨价。D02 未解决前不实现“30帧动作锁内立即重闪”的隐藏取消能力。

## 6. 组件与数据

| 类型（建议新增） | 关键字段/职责 |
|---|---|
| PlayerState | 位置速度、支撑实体、朝向、Alive、耐力、档位、次数、锁集合 |
| ActionState | 动作实例ID、帧位、阶段、是否已成功、防重复命中集 |
| CharacterRules | 世界单位速度/重力/碰撞尺寸、动作参数、档位表 |
| StaminaChange | 原因、前值、后值、Tick；HUD只读 |
| PlayerView | 胶囊视觉、武器视觉、Trail、Animator；读取快照 |

View 建议根节点为稳定坐标，Visual 子节点承载翻转和形变，WeaponVisual 与受击/攻击 DebugShape 分离。缩放视觉不改变权威碰撞尺寸，避免反馈动作让玩家意外撞刺。
